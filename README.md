# Prime Numbers from 1 to N

A simple Java program to print all prime numbers between **1 and N**.

## 📌 Description

This program takes a number `N` as input and prints all the prime numbers from `1` to `N`.

A prime number is a number greater than 1 that has only two factors: **1 and itself**.

## 💻 Example

**Input:**

```text
Enter N: 20
```

**Output:**

```text
Prime numbers from 1 to 20:
2 3 5 7 11 13 17 19
```

## 🛠️ Technologies Used

* Java
* JDK

## ▶️ How to Run

Compile the program:

```bash
javac PrimeNumbers.java
```

Run the program:

```bash
java PrimeNumbers
```
